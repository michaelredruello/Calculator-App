# React Calculator

A minimal retro-style calculator built with React. Users can dynamically add or remove rows, set plus/minus signs, and enable/disable each input. The total updates live as the user types. The UI is inspired by the aesthetic of _Digseum_.

## Features

- Add/remove input rows
- Enable/disable rows individually
- Choose between addition and subtraction per row
- Real-time total update

### Installation

```bash
git clone https://github.com/michaelredruello/Calculator-App.git
cd calculator-app
npm install
npm run dev
```
